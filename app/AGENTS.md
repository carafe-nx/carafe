# Carafe app agent instructions

These instructions apply to `app/` and its subdirectories, together with [../AGENTS.md](../AGENTS.md).

Before changing the app, read [the Carafe app section of docs/development.md](../docs/development.md#carafe-app-app)
and all following sections. They define the crate boundaries, dependency direction, Rust and TypeScript
conventions, generated bindings, localization, styles and app checks.

For changes to the running window, read "Driving the window" in that document before using the CDP commands.
